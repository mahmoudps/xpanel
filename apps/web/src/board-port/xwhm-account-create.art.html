Create account

The account gets its own UID, slice and quotas. Nothing is created on the server until the reconciler applies it.

Identity
3 to 16 characters: lowercase letters and digits, starting with a letter. It becomes the Linux user, the home directory and the database prefix. Available: no account, reseller or system user is called salma.
Without www. A DNS zone and a mail domain are created for it. Not hosted on this server yet.
Receives quota, suspension and certificate notices. Use an address outside this account, so notices still arrive if the account is suspended.
